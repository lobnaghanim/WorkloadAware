# Exploratory scripts

These 8 scripts are early/exploratory work, absent from the audited reproduction
command sequence in [`docs/REPRODUCIBILITY.md`](../../docs/REPRODUCIBILITY.md) and
superseded by the final all-workload pipeline (`evaluate_physical_candidates.py`,
`select_k1_all.py`, `create_k1_all_designs.py`, `run_k1_booksim.py`,
`summarize_k1_all.py`, and the final policy-comparison scripts).

Kept for history rather than deleted, per
[`docs/CLEANUP_RECOMMENDATIONS.md`](../../docs/CLEANUP_RECOMMENDATIONS.md).
Their associated early result files (e.g. `results/baseline_transpose.json`,
`results/manual_3_12_transpose.json`, `results/baseline_test.json.json`,
`results/physical_mesh_8phy_baseline.json.json`) remain in `results/` and were
not moved.
