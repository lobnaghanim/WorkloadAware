# Experiment Index

This index maps each major project phase to its current authoritative scripts, primary inputs, outputs, and purpose. For exact command order and prerequisites, see [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md).

| STAGE comparison | [`compare_stage_policies.py`](../project/compare_stage_policies.py) | STAGE Mesh/Fixed/Aware selections, designs, and result JSONs | [`stage_policy_comparison.csv`](../results/stage_policy_comparison.csv)<br>[`stage_policy_summary.csv`](../results/stage_policy_summary.csv) | Compare policy latency, hops, analytical metrics, wire, actual links, and derived latency knee for all STAGE configurations. |
